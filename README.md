## 📖 项目简介
果粉论坛，是面向苹果产品爱好者的交流社区项目。
本仓库内置了**大脑芯片等级测试网页**，通过20道脑力测评题目，根据得分匹配历代Apple芯片（从初代S5L8900到M4 Ultra），用来趣味评估脑力水平。

社区方向：
- iPhone / iPad / Mac / Apple Watch 全系列产品讨论
- iOS、macOS 玩机技巧、使用心得、问题求助
- 新品爆料、硬件评测、二手避坑、苹果生态分享
- 趣味脑力测试：大脑芯片等级测试

> ⚠️ 注意：本测试仅为趣味娱乐，**不具备专业心理/智力测评效力**。

## ✨ 功能介绍
- 20道脑力测评单选题目
- 实时自动计算总分（0~200分）
- 根据分数自动匹配对应的Apple芯片型号，附带芯片介绍
- 移动端适配，深色渐变风格UI
- 支持重新测试，分数实时刷新
